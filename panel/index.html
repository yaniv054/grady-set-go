      Generate

      Tick folders in the media list (☐ next to a folder) to fill the day from them, including subfolders. Read-only on the share.

      Creates and saves playlists only for days that have none. Days that already have a playlist are left unchanged. Clips used earlier in the batch go to the back of the queue.

      Blocks pinned to a date (Insert at a time, or an occasion) keep their times; clips fill the time around them.

      Saved blocks

        Pre-edited slots for reuse (topical days and the like). Select rows in the playlist to save them as a block. Warnings are checked for today's broadcast day.

        Occasions

          Days like Memorial Day: enter each date by hand. On those dates Generate and Fill use the occasion's branding set and place its blocks at their times.

            Library

            Export CSV

            Metadata for each clip in library.csv, stored on this PC in data\clip-metadata.json. Nothing on the share is changed. Duplicate copies of a file share one record. For bulk editing: Export CSV, edit in Excel, save as CSV UTF-8, Import CSV.

            Overnight analysis

            Idle

            Runs on this PC at low priority, so playout keeps priority. Audio reads each file completely (loudness, clipping, mono, silences); Video checks three 10-second samples plus the start and end (combing, black, static picture); Metadata suggests titles and performers from the file and folder names; Thumbnail saves one picture per clip (a few seconds per clip) in data\thumbs. Clean titles (off by default) stores the cleaned-up title from the Metadata check (show and artist names and dates kept) as clip metadata, for clips whose title is still the raw file name; files on the share are never renamed. A stopped run continues where it left off next time. Nothing on the share is changed. Leave “Stop at” empty to run until done.

            Channel & schedule

            Channel
            Broadcast day

            Plays whenever the playlist runs out or a file fails, so the stream never goes black. A folder rotates its clips.

            Channel logo
            No logo uploaded

            A transparent PNG works best. It is saved in ffplayout storage as 00-assets\channel-logo.png. Tick “Show logo” above and Save channel to put it on air (needs a playout restart).

            Position is an ffmpeg overlay expression: W-w-12:12 = top right, 12:12 = top left, W-w-12:H-h-12 = bottom right.

            Loudness (EBU R128)

            −23 LUFS is the broadcast (EBU R128) target. YouTube normalises to about −14 LUFS, so quieter streams are not turned up.

            Automation account

            Lower thirds run on this PC without a browser open, so the panel signs in to ffplayout with its own account. Create a separate ffplayout user for it (in the ffplayout UI), then enter it here. It is stored on this PC in data\panel-secrets.json.

            Lower thirds (now / next)

            Live input

            When a live source connects, it takes over the playout; when it disconnects, the schedule resumes. Up to 8 listeners. Higher priority wins.

            OnNameTypeListen onPortApp / keyPrioritySend to

            “This PC only” (127.0.0.1) accepts sources on this machine only. Pick “All interfaces” for an encoder elsewhere on the network, and allow the port in Windows Firewall.

            Capture devices on this PC

            Send a camera and a microphone connected to this PC to a live input listener. Choose them like in a video call: the preview shows what will be sent. Nothing is sent until you press Send to live input.

            No preview

            Sample peak, dBFS

            ON AIR

            Sends 1920×1080, 25 fps, H.264 at about 6 Mbit/s with 48 kHz stereo sound. ffplayout takes over the broadcast as soon as the live input receives the stream, and goes back to the playlist when you press Stop. Log: logs\capture.log.

            Channel branding

            Upload the channel's branding files here. Each file is checked against the branding kit spec (1920×1080, 25 fps progressive, 48 kHz stereo, −14 LUFS) the moment it arrives. Files are stored in storage\branding; replaced or removed files are moved aside, never deleted.

            Playlist rules

            Applied when a day is built with “Add branding” ticked on the Program page. Only files that passed the check are used; each type is rotated.

            Live text

            Drawn by the playout over what is playing, using the lower-third font settings on the Channel & schedule page and the automation account set there. There is one text layer: on an explicit clip the tag shows first, then the lower third. Not yet seen on air; check the look on the TEST channel.

            System settings
            
      
            Decisions that apply to the whole installation: the panel, the boot script and the engine follow them. Only an administrator can change them. Stored in data\system.json.
            
      
            
        
            
          
            
            After a reboot or an engine restart
            
            
            
            The panel records every Start, Stop and Restart it sends to ffplayout. At boot (and after the watchdog restarts a crashed engine) the boot script asks the panel to resume; the panel starts the channel only when the last recorded state was on air, within this age, and the automation account is set on the Channel & schedule page. Commands given in ffplayout's own UI are not recorded.

            Logo in the menu
            
                
                
            
              
            Logo on the sign-in page
            
                
                
            
            
            
            
            
            
              
              
            • Format: PNG or SVG with a transparent background (also JPEG, WebP, GIF). Up to 1 MB.
              • 
              
            • Size: wide, about 320 × 72 pixels (shown at up to 160 × 36 in the menu, 260 × 64 on the sign-in page). Use twice that for sharp screens; very tall pictures get small.
              • 
              
            • Colour: the screen can be dark or light, so check both previews. A pure black or pure white logo disappears on one of them; use mid-tone colours, or give the logo its own solid background.
              • 
              
            • A replaced logo is kept aside in the data folder. A very dark accent colour is hard to read on the dark theme.

            Language and formats
            
            
            
            Each person picks a language in the side bar; it is remembered in that browser. The default here applies to browsers that have not picked one. Dates are shown in the order of the language (or the order chosen above); times are always 24-hour; digits are always 0-9. Typing a date accepts the same order.

            Hidden media
            
      
            Files and file types hidden from the system: they are left out of the Library, Generate, the folder browser and the overnight analysis. Nothing on the share is moved, renamed or deleted. A mark stays while the file at that path has the same content: a file replaced by a fixed version shows again by itself.
            
      
            
      
            
      
            
      
            
      
            
      
            
    
            
    
            
      
            Needs attention
            
      
            Files that need a decision. Hide takes a file out of the Library, Generate, the folder browser and the overnight analysis until you unhide it on the Hidden media page; nothing on the share is moved, renamed or deleted. Keep as is clears an item; it comes back only if something new is found. To fix or delete a file, use Show in folder.
